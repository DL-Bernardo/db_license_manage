Anti-Piracy

Database Duplicate Detection & Hardware Lockout

Tokens are cryptographically bound to the unique database UUID. If an unauthorized party copies or restores the database on another server, the system detects the mismatch instantly.

  • Prevents unauthorized database restoration in rogue environments
  • Displays clear "License is invalid for this database UUID" alerts
  • Superuser/Administrator bypass guarantees administrators never get locked out
